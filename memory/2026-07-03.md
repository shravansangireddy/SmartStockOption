## Options Scanner: Finnhub + Yahoo Finance Toggle

### What was built
- **Data source toggle** in the sidebar: ☁ Yahoo / ⚡ Finnhub
- Provider badge in the HeroStatStrip showing active source
- All API endpoints accept `?provider=finnhub` or `?provider=yahoo` (default: yahoo)
- `/api/provider-status` endpoint shows health + capabilities of each provider
- Finnhub free tier: quotes/news/profile only (options & candles 403) → graceful fallback to Yahoo
- Finnhub uses ETF proxies for indices (DIA for ^DJI, QQQ for ^IXIC)
